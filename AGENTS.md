# Convention des fichiers PHP

À la demande de l’utilisateur, tous les fichiers PHP sauf `index.php` doivent commencer par `get` ou `set`, avec une extension `.php`.

Noms actuels : `getApi.php`, `getRouter.php`, `lib/getAdventure.php`. Mettre à jour les appels JavaScript, les inclusions PHP, les tests et les instructions de démarrage à chaque renommage.
